自己申告では △ が14分野、△△ が10分野。だが**この人の自己申告は下振れする**
（診断#000で証明済み）。全部を「基礎から固める」と時間が足りない。

- 「忘れているだけ」→ 復習キューに載せれば5〜10分で復活する
- 「本当に穴」→ 腰を据えた学習が必要（1分野あたり数時間）

- 1問1〜2分。**計算より「核心を思い出せるか」を見る**
- 何も見ないで答える。分からなければ即「分からない」（考え込まない）
- 判定：
  - **A** すぐ答えられた → 生きている。復習キューへ（低頻度）
  - **B** 少し考えて答えられた → 忘れかけ。復習キューへ（高頻度）
  - **C** 言われれば思い出す → 忘れている。**再学習は軽くて済む**
  - **D** まったく出てこない → **本当の穴。腰を据えて学習**

# 解答（解いてから見ること）

**A-1** 傾き＝加速度、面積＝変位
**A-2** N = mg cosθ
**A-3** ½kx²　／　エネルギー保存 ½kx² = ½mv² より **v = x√(k/m)**
**A-4** 鉛直成分 v₀sinθ が 0 になる時刻。**t = v₀sinθ / g**
**A-5** M = F × (支点から力の作用線までの距離)。この場合 **M = FL**
**A-6** e = |衝突後の相対速度| / |衝突前の相対速度| = −(v₁'−v₂')/(v₁−v₂)
**A-7** 大きさ a = v²/r、向きは**常に円の中心向き**（速度と垂直）
**A-8** ω = √(K/m) より **T = 2π√(m/K)**。ばね振り子は K=k なので **T = 2π√(m/k)**
**A-9** U = −GMm/r。**基準は無限遠（そこで U=0）**。だから常に負

**B-1** C = mc。温度上昇 ΔT = Q/C
**B-2** 固定端反射：位相が **π ずれる**（山→谷）。自由端反射：位相は**変わらない**
**B-3** 閉管の基本振動は「閉端が節・開端が腹」で管長が波長の1/4。**λ = 4L**
**B-4** pV = nRT　／　U = (3/2)nRT
**B-5** ΔU = Q + W（W は気体が「された」仕事）。断熱で Q=0、膨張すると気体は
　　　外へ仕事をする＝W<0。よって ΔU<0 で **温度は下がる**
**B-6** 位置 x での位相の遅れ。x だけ離れた場所には、波が伝わるのに時間がかかる
**B-7** 波長は**縮む**。振動数は**高くなる**（音が高く聞こえる）
**B-8** 速さ 1/n 倍、波長 1/n 倍、**振動数は変わらない**（波源が決めるから）
**B-9** 明線条件：光路差 = mλ（m は整数）。ヤングでは dx/L = mλ。
　　　位相のπずれ：**屈折率の小さい媒質から大きい媒質へ向かう境界での反射**

**C-1** 1/R = 1/3 + 1/6 = 1/2 → **R = 2.0Ω**（並列は必ず最小の抵抗より小さい）
**C-2** 電圧比 1:10（巻数比と同じ）／電流比 10:1（電力が保存されるので逆比）
**C-3** α線＝ヘリウム原子核 ⁴₂He、β線＝電子、γ線＝電磁波（光子）
**C-4** 電界はベクトル（単位電荷が受ける力）、電位はスカラー（単位電荷あたりの
　　　位置エネルギー）。点電荷の電位 **V = kQ/r**（電界は kQ/r² なので混同注意）
**C-5** 容量は ε 倍に増える。**電池をつないだまま → 電圧 V が一定**（電荷が増える）。
　　　**電池を切り離してから → 電荷 Q が一定**（電圧が下がる）
**C-6** I = E/(R+r)
**C-7** f = qvB（v と B が垂直のとき）。向きはフレミング左手（正電荷の場合）
**C-8** 「誘導電流は、その原因となる磁束の変化を妨げる向きに流れる」。
　　　N極を近づける → 上面がN極になる向き（＝磁石を押し返す向き）に流れる
**C-9** コイルでは電流の位相が電圧より **π/2 遅れる**。共振周波数 **f = 1/(2π√(LC))**
**C-10** 強さ↑ → 飛び出す**光電子の数**が増える。振動数↑ → 光電子の**運動エネルギー**が増える
**C-11** (1/2)³ = **1/8**。質量欠損＝原子核の質量が、構成する核子の質量の和より
　　　小さいこと。その差が結合エネルギー E = Δmc² として放出されている
