# 発展レベル診断 #002 — 単振動（誘導つき大問）

実施日: 2026-09-03
目的: 「公式が言えるか」ではなく **「難関大の大問が解けるか」** を測る
背景: 東大模試「弾性力」大問 2/20 の原因特定

## 問題

ばね定数 k の軽いばねを鉛直に立て、下端を床に固定し、上端に質量 **M** の皿を
取り付ける。皿の上に質量 **m** の小球を乗せる。重力加速度を g とする。
運動は鉛直方向のみ、摩擦・空気抵抗は無視。皿と小球は互いに離れることができる。

(1) 全体が静止してつり合っているとき、ばねは自然長から d₀ だけ縮んでいる。d₀ は？
(2) つり合いの位置から皿と小球を一体のまま鉛直下向きに A だけ押し下げ、静かに放した。
　　離れずに運動する間、これは単振動になる。角振動数 ω と周期 T は？
(3) 一体で運動している間、小球が皿から受ける垂直抗力 N を、つり合いの位置からの
　　変位 x（鉛直上向きを正）で表せ。
(4) 小球が皿から離れないための振幅 A の条件は？
(5) A がその条件を満たさないとき、小球が皿から離れるのはどの位置か。

## 結果

| 小問 | 結果 |
|---|---|
| (1) | **○ 自力で正解**。(M+m)g = kd₀ → d₀ = (M+m)g/k |
| (2)〜(5) | **未着手**（(2)の途中で断念）|

### 詰まった原因（本人の発言そのまま）

> なんとか公式を一つ思い出すのに苦労して
> x = A sinωt
> 一つあれば戦えるよね
> ...うーんやっぱりしんどい？
> あーきらめた

**→ 単振動の入口を x = A sin ωt だと誤って記憶していた。**
これは解であって出発点ではない。正しい入口は運動方程式 ma = −Kx。
詳細は `docs/つまずきポイント集.md` および `docs/解法の型カタログ.md`。

### 重要な観察

**(1) を自力で正解している。** つり合いの式が立てられるということは、
単振動の Step 1（振動の中心を見つける）が既にできているということ。
土台は既にあり、欠けているのは **Step 2 への繋ぎ方** だけ。
「単振動が苦手」ではなく「単振動の入口の配線が1本違う」が正確な診断。

---

## 解答

### (1)
つり合いの式（上向き正）: kd₀ − (M+m)g = 0
→ **d₀ = (M+m)g / k**

### (2)
つり合いの位置を原点、鉛直上向きを正として変位 x を取る。
このときばねの縮みは (d₀ − x) なので、ばねが押し上げる力は k(d₀ − x)。

一体（質量 M+m）の運動方程式:
```
(M+m)a = k(d₀ − x) − (M+m)g
       = kd₀ − kx − (M+m)g
```
ここで (1) より kd₀ = (M+m)g なので、**定数項が消えて**
```
(M+m)a = −kx
```
**これが「つり合いの位置を中心に取る」ことの威力。重力が消える。**

よって a = −{k/(M+m)}x なので
**ω = √(k/(M+m))　／　T = 2π√((M+m)/k)**

### (3)
**小球だけ**に注目する（系全体では N は内力なので出てこない）。
小球にはたらく力は、重力 mg（下向き）と垂直抗力 N（上向き）。

上向き正の運動方程式: ma = N − mg
(2) より a = −{k/(M+m)}x を代入して
```
N = mg + ma = mg − mkx/(M+m)
```
**N = mg − mkx/(M+m)**

（検算：x=0 すなわちつり合いの位置では N = mg。静止時と一致する。○）

### (4)
N ≥ 0 が、運動する全範囲 −A ≤ x ≤ A で成り立てばよい。
N は x が最大のとき最小になるので、x = A のとき:
```
mg − mkA/(M+m) ≥ 0
```
→ **A ≤ (M+m)g / k　（＝ d₀）**

**振幅の限界が、つり合いでの縮み d₀ にちょうど一致する。**
つまり「ばねが自然長を超えて伸びようとすると、小球は離れる」。

### (5)
N = 0 となる x を求める:
```
mg = mkx/(M+m)　→　x = (M+m)g/k = d₀
```
つり合いの位置から d₀ だけ上。このときばねの縮みは d₀ − d₀ = 0。

→ **ばねがちょうど自然長になる位置で離れる。**

### この問題で問われていた力

| 小問 | 要求される力 |
|---|---|
| (1) | つり合いの立式（＝振動の中心の特定）|
| (2) | 中心からの変位で運動方程式 → ma=−Kx の形に整理する型 |
| (3) | **注目物体を切り替える**（系全体 → 小球単独）|
| (4) | 限界条件を不等式で立てる（N ≥ 0）|
| (5) | 限界の物理的意味を読む |

**三角関数は一度も使っていない。** これが「x = A sin ωt から始めない」ということ。
