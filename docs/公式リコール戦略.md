## 第1層：30秒で作る（覚えなくていい）

覚えるのをやめて、**作る手順ごと**覚える。目標は各30秒。

| 式 | 作り方（30秒ルート） |
|---|---|
| v = v₀ + at | 加速度の定義そのもの |
| x = v₀t + ½at² | v-t グラフの台形の面積 |
| v² − v₀² = 2ax | 上2つから t を消す |
| ½mv² − ½mv₀² = W | 運動方程式に x を掛ける |
| 力学的エネルギー保存 | 上の式で W が重力の仕事だけの場合 |
| 直列 R = R₁+R₂ | **電流が共通** → 電圧を足す |
| 並列 1/R = 1/R₁+1/R₂ | **電圧が共通** → 電流を足す |
| 並列 C = C₁+C₂ | **電圧が共通** → 電気量を足す |
| 直列 1/C = 1/C₁+1/C₂ | **電気量が共通** → 電圧を足す |
| a = v²/r = rω² | 円運動の加速度 |
| T = 2π√(m/K) | F = −Kx → ma = −Kx → ω=√(K/m) |
| 単振り子 T = 2π√(l/g) | 復元力 K = mg/l を上に代入 |
| U = ½QV = ½CV² | Q-V グラフの三角形の面積 |
| 気体がした仕事 | p-V グラフの下の面積 |

**ポイント：回路の合成は「何が共通か」だけ覚える。**
直列＝一本道だから電流が共通。並列＝分岐だから電圧が共通。
コンデンサーが抵抗と逆になる理由も、これで自動的に出る。

## 忘れた公式を復元する最強ツール：次元解析

診断 Q1 で次元感覚が弱いことが判明した。**ここを鍛えると「忘れた」が怖くなくなる。**

### 例：単振り子の周期を完全に忘れた

1. 求めたいものの単位を書く： T は [s]
2. 関係しそうな量を並べる： 長さ l [m]、重力加速度 g [m/s²]、質量 m [kg]
3. T ∝ l^a · g^b · m^c と置いて単位を合わせる：

```
s = m^a · (m/s²)^b · kg^c
  s について :  −2b = 1   → b = −1/2
  m について :   a + b = 0 → a = +1/2
  kg について:      c = 0   ← 質量は入らない！
```

4. → **T ∝ √(l/g)**。あとは係数 2π だけ覚えていればいい。

**おまけの収穫：** 「質量に依らない」という物理的結論まで同時に出る。

### 使える場面

- ばね振り子 T ∝ √(m/k)（k は [kg/s²]）
- 音速 v ∝ √(K/ρ)
- 答えの検算：出した答えの単位が合わなければ、その時点で間違い

## 導出の「型」は5つしかない

毎回ゼロから考えているから遅い。**型を当てはめる作業に変える。**

| 型 | 中身 | 例 |
|---|---|---|
| 型1 **定義に戻る** | 定義式をそのまま書く | 加速度＝速度の変化率、電位＝単位電荷あたりの位置エネルギー |
| 型2 **グラフの面積・傾き** | 面積＝積、傾き＝率 | v-t の面積＝変位、Q-V の面積＝静電エネルギー、p-V の面積＝仕事 |
| 型3 **保存則を書く** | 保存する量を左辺＝右辺 | 運動量保存、エネルギー保存、電気量保存 |
| 型4 **微小量で考えて足す** | Δ で書いて極限 | 誘導起電力 V = −ΔΦ/Δt、微小仕事 |
| 型5 **次元と極限でチェック** | 形を復元・検算 | 上記の次元解析、m→∞ や θ→0 で妥当性確認 |

## 検算の作法（「自信あり」で間違えるのを防ぐ）

診断 Q9 で、自信満々のまま誤答した。これが一番失点が大きいパターン。
**計算する前に、答えの範囲を先に決める。**

| 場面 | 事前チェック |
|---|---|
| 並列の合成抵抗 | **必ず一番小さい抵抗より小さい** |
| 直列の合成抵抗 | 必ず一番大きい抵抗より大きい |
| 並列の合成容量 | 必ず一番大きい容量より大きい（抵抗と逆） |
| 衝突後の速さ | 完全非弾性なら運動エネルギーは必ず減る |
| 斜面をすべる速さ | 角度に依らない（なめらかなら） |
| どんな式でも | **単位が合うか** |
