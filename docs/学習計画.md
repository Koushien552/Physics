## 診断で判明した「本当の課題」

当初の想定は「物理が苦手 → 基礎から積み直す」。**これは棄却された。**

| 証拠 | 示すこと |
|---|---|
| 診断#000 を紙なしの暗算で 9.5/12 | 力学基礎は完成している |
| 「速さはスカラーだから…」と自力で説明 | 概念理解はむしろ強い |
| 東大模試 コンデンサー **20/20** | 習えば最難関レベルで満点を取れる |
| 東大模試 弾性力 2/20・気体 0/20 | 習っていない／忘れた分野は壊滅 |
| 本人「時間が経てばコンデンサーも0点になる」 | 保持できていない自覚がある |
| 本人「公式忘れた→導出しよ→時間切れ」 | 想起が遅く、試験時間内に間に合わない |

> **結論：理解力の問題ではなく、保持（リテンション）と想起の問題。**
> 点数の偏りは能力の偏りではなく、「学習からの経過時間」の関数になっている。

したがって基礎の積み直しは時間の無駄。**やるべきは、
①忘れない仕組みを先に入れる ②想起を高速化する ③空いている穴を埋める。**

### 2-A 熱力学（気体）— 模試 0/20
7章 気体分子の運動（状態方程式 → 分子運動論 → 内部エネルギー）
→ 8章 気体の状態変化（第一法則 → 4つの変化 → モル比熱 → 熱機関）

重点:

- 定積・定圧・等温・断熱で **Q, W, ΔU のどれが0になるか**の表を自分で書けるようにする
- p-V グラフの面積＝仕事（`公式リコール戦略` の型2）
- 分子運動論の導出は**運動量・力積**が前提。ここは診断で★3なので接続できる

### 2-B 単振動 — 模試 2/20

重点:

## 設計思想

1. **忘れない仕組みが先、新単元は後。** 穴の空いたバケツに水を注がない
2. **強みを潰さない。** 導出癖は難関大では武器。捨てずに「速くする」
3. **できている所に時間を使わない。** 力学基礎の復習に時間を割かない
4. **自信を伴う誤答を最優先で潰す。**（診断 Q9 の「簡単！」で誤答が典型）
5. **偏差を縮める。** 満点の大問1つより、全大問6割の方が総合点は高い
