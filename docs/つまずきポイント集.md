間違えた問題は必ずここに **「何を誤解していたか」** の形で記録する。
単に「計算ミス」で終わらせず、思考のどこが分岐したかを書く。

書式:
```
### [単元コード] 一行タイトル
- 出題: どんな問題だったか
- 誤答: 何と答えたか
- 誤解の正体: なぜそう考えたか（ここが本体）
- 正しい考え方:
- 再発防止の合言葉:
- 再テスト: 未 / 済(日付・正誤)
```

### [D4] 「並列」と聞いて頭に直列の回路図が浮かぶ
- 出題: 3.0Ω と 6.0Ω を**並列**、9.0V。合成抵抗と全電流は？（診断#000 Q9）
- 誤答: 9Ω、1A（しかも自信度「簡単！」）
- 誤解の正体: **公式忘れではない。本人の自己申告→「並列って書いてるのに頭の中で
  直列のイメージを浮かべていた」。用語と回路図の対応が逆に配線されている。**
  知識の欠落ではなく、ラベル↔図の誤配線。だから自信を伴う誤答になった（最も危険）。
- 正しい考え方:
  - 漢字がそのまま図：**直**列＝まっすぐ一本道／**並**列＝横に並んで分岐
  - 一本道 → 電流が共通 → 電圧を足す → R = R₁+R₂
  - 分岐 → 電圧が共通 → 電流を足す → 1/R = 1/R₁+1/R₂ → **R = 2.0Ω, I = 4.5A**
- 再発防止の合言葉: **「並列の合成抵抗は、必ず一番小さい抵抗より小さい」**
  → 3.0 と 6.0 の並列なら、計算前に「答えは3.0未満」と確定できる。9Ωは即棄却。
  さらに、回路図を見たら必ず声に出して「これは分岐している／していない」と確認する。
- 派生注意: **コンデンサーは逆になる**（並列で C を足す）。理由は同じ「何が共通か」から出る。
- 再テスト: 未

### [C1] 媒質が変わったとき、何が変わらないのかが未整理
- 出題: 500Hz・波長0.68m の音が空気中→水中へ進む。振動数・波長・速さのうち
  変化しないのは？（診断#000 Q8(2)）
- 誤答: 「波長？？」
- 誤解の正体: 「媒質が変わる＝波の性質が変わる」までは合っているが、
  **何が波源由来で、何が媒質由来かの切り分けができていない。**
- 正しい考え方:
  - **振動数 f は波源が決める。** 音源が1秒間に500回振動しているなら、
    どんな媒質に入っても、境界を1秒間に通過する波の数は500個のまま。
    （もし変わったら、境界で波が消えるか溜まるかしてしまう）
  - **速さ v は媒質が決める。**（水中の音速は空気中の約4.4倍）
  - よって λ = v/f より、**波長は速さと同じ割合で変わる。**
  - 光でも同じ：屈折で振動数は不変、波長は 1/n 倍になる（だから色は変わらない）
- 再発防止の合言葉: **「振動数は波源のもの、速さは媒質のもの、波長はそのしわ寄せ」**
- 再テスト: 未

### [B1] 熱容量の定義が出てこない
- 出題: 比熱と熱容量の違いを一言で（診断#000 Q10）
- 誤答: 比熱は正答。「熱容量ってなんだ？」
- 誤解の正体: 比熱（物質固有の量）は覚えていたが、**熱容量（その物体固有の量）**
  という「対」の存在が抜けていた。
- 正しい考え方:
  - 比熱 c ：**1g** の物質を 1K 上げるのに必要な熱量 [J/(g·K)] — **物質**で決まる
  - 熱容量 C ：**その物体まるごと**を 1K 上げるのに必要な熱量 [J/K] — **物体**で決まる
  - 関係： **C = mc**　／　熱量： Q = CΔT = mcΔT
  - 単位を見れば区別できる：比熱には g が入っている、熱容量には入っていない
- 再発防止の合言葉: **「比熱は物質のスペック、熱容量はその個体のスペック」**
- 再テスト: 未

### [A9] 「向心力は仕事をしない」の理由が不正確
- 出題: 等速円運動の向心力は仕事をするか（診断#000 Q12(2)）
- 誤答: 「No。一周回ったら元通りだし」（結論は正解、**理由が誤り**）
- 誤解の正体: 「一周で元に戻る＝仕事の総和が0」という論法を使った。これだと
  **「途中では仕事をしているが、正負が打ち消し合って0」** という意味になってしまう。
  実際には向心力は**瞬間ごとに**仕事が0。
- 正しい考え方:
  - 仕事 W = F·s·cosθ。**向心力は常に速度（＝変位の向き）と垂直**なので cos90°= 0。
    → 微小時間ごとに仕事が 0。だから速さが変わらない。
  - **反例で違いを実感する：** 楕円軌道の万有引力は「一周すれば仕事0」だが、
    途中では正の仕事も負の仕事もしている（だから速さが変化する＝ケプラー第2法則）。
    「一周で0」と「常に0」は全くの別物。
  - 同様に「仕事をしない力」の常連：垂直抗力、糸の張力（伸びない糸）、
    磁場中の荷電粒子が受けるローレンツ力
- 再発防止の合言葉: **「力と速度が垂直なら、その瞬間の仕事は0」**
- 再テスト: 未

### [横断] 次元感覚が武器になっていない
- 出題: エネルギーと同じ次元のものを選べ（診断#000 Q1）
- 誤答: 結論は正解（a,b,c）だが、**(b) kg·m²/s² は「勘」**だった。
  Q11 で ½mv² を計算した後に「あ、Q1のbは正解だなあ」と事後的に気づいた。
- 誤解の正体: 単位を「公式の付属品」として扱っており、**単位から公式を復元する
  ツール**として使えていない。これが「公式忘れた→導出→時間切れ」の一因。
- 正しい考え方: `docs/公式リコール戦略.md` の次元解析セクション参照。
  - J = N·m = (kg·m/s²)·m = **kg·m²/s²** ← これは即答できるべき
  - 逆に kg·m/s は運動量、N/m はばね定数
- 再発防止の合言葉: **「答えを出したら単位を確認。単位が合わなければ必ず間違い」**
- 再テスト: 未
