# ■ 物理基礎

## 第1編 運動とエネルギー

### 1章 運動の表し方 〔基〕
物理量と単位／有効数字／速度・変位／相対速度／加速度／
等加速度直線運動の3公式／v-t グラフ／落体の運動（自由落下・鉛直投げ上げ・投げ下ろし）

### 2章 力と運動の法則 〔基〕
力の表し方・合成分解／力のつり合い／**作用反作用の法則**／
運動の第1法則（慣性）／**運動の第2法則 ma=F**／
静止摩擦力・最大静止摩擦力・動摩擦力／空気抵抗と終端速度／
圧力・水圧・浮力（アルキメデスの原理）

### 3章 仕事とエネルギー 〔基〕
仕事の定義 W=Fs cosθ／仕事率／運動エネルギー／
重力による位置エネルギー／**弾性力による位置エネルギー ½kx²**／
力学的エネルギー保存則／保存則が成り立つ条件

## 第2編 熱

### 4章 熱とエネルギー 〔基〕
熱と温度／絶対温度／熱運動／熱平衡／**熱量保存則**／
**比熱と熱容量（Q=mcΔT=CΔT）**／潜熱・状態変化／
熱と仕事／内部エネルギーの初歩／熱効率／不可逆変化／エネルギー保存

## 第3編 波

### 5章 波の性質 〔基〕
波と媒質／横波と縦波／波の要素（波長・振動数・周期・振幅）／
**v = fλ**／y-x グラフと y-t グラフ／重ね合わせの原理／
波の干渉／定常波（腹と節）／自由端反射・固定端反射

### 6章 音 〔基〕
音の速さ／音の3要素／うなり／弦の振動／気柱の共鳴（開管・閉管）／開口端補正

## 第4編 電気

### 7章 物質と電気抵抗 〔基〕
電荷／電流の定義／**オームの法則 V=RI**／抵抗率と温度／
**抵抗の直列・並列接続**／電力・電力量／ジュール熱

### 8章 電気の利用 〔基〕
磁界／電流と磁界／電磁誘導のあらまし／発電の仕組み／
交流の発生／実効値／変圧器と送電／電磁波の種類と利用

## 第5編 物理学と社会

### 9章 エネルギーとその利用 〔基〕
エネルギーの変換と保存／各種発電／原子力／放射線とその利用・被曝

# ■ 物理

## 第1編 力と運動

### 1章 平面内の運動 〔物〕
速度・加速度のベクトル的扱い／相対速度（2次元）／
**水平投射・斜方投射**（水平方向と鉛直方向を独立に扱う）

### 2章 剛体のつり合い 〔物〕
**力のモーメント**／剛体のつり合いの条件（力の和＝0 かつ モーメントの和＝0）／
偶力／重心の求め方

### 3章 運動量 〔物〕
**運動量と力積 mv'−mv = Ft**／**運動量保存則**（成り立つ条件＝外力が働かない）／
**反発係数（はねかえり係数）e**／弾性衝突・非弾性衝突・完全非弾性衝突／2次元の衝突

### 4章 円運動 〔物〕
等速円運動／角速度／周期／**向心加速度 a = v²/r = rω²**／向心力／
**慣性力**／遠心力／鉛直面内の円運動（最高点の条件）

### 5章 単振動 〔物〕　★模試で失点した領域
単振動と等速円運動の射影／変位・速度・加速度の式／
**復元力 F = −Kx → ω=√(K/m)、T = 2π√(m/K)**／
**ばね振り子**（水平・鉛直・2本のばね）／**単振り子**／
単振動のエネルギー（弾性エネルギーと運動エネルギーのやりとり）

### 6章 万有引力 〔物〕
ケプラーの3法則／**万有引力の法則 F=GMm/r²**／重力と万有引力／
**万有引力による位置エネルギー U = −GMm/r**（基準は無限遠）／
第1宇宙速度・第2宇宙速度

## 第2編 熱と気体

### 7章 気体分子の運動 〔物〕　★模試で失点した領域
**理想気体の状態方程式 pV = nRT**／ボイル・シャルルの法則／
**気体分子運動論**（分子1個の力積 → p = Nmv²/3V の導出）／
根二乗平均速度／**内部エネルギー U = (3/2)nRT（単原子分子理想気体）**

### 8章 気体の状態変化 〔物〕　★模試で 0/20 の領域
**熱力学第一法則 ΔU = Q + W**（W は気体が「された」仕事）／
気体がする仕事＝p-V グラフの下の面積／
**定積変化・定圧変化・等温変化・断熱変化**（各過程で Q, W, ΔU のどれが0か）／
定積モル比熱・定圧モル比熱／マイヤーの関係 Cp = Cv + R／
ポアソンの関係／熱機関と熱効率／不可逆変化

## 第3編 波

### 9章 波の伝わり方 〔物〕
**正弦波の式 y = A sin2π(t/T − x/λ)**／位相／
ホイヘンスの原理／反射・屈折の法則／回折／干渉（2つの波源）

### 10章 音 〔物〕
**ドップラー効果**（音源が動く場合・観測者が動く場合・両方・風がある場合）／
斜め方向のドップラー／衝撃波

### 11章 光 〔物〕
光の速さ／**絶対屈折率 n = c/v**／相対屈折率／**全反射と臨界角**／
分散とスペクトル／散乱／偏光／
**レンズの式 1/a + 1/b = 1/f**／倍率／実像と虚像／球面鏡

### 12章 光の干渉と回折 〔物〕　★最頻出
**ヤングの実験**／**回折格子**／**薄膜による干渉**／
**くさび形空気層**／**ニュートンリング**／単スリットによる回折／
**反射による位相のπずれ**（屈折率の大小で決まる）

## 第4編 電気と磁気

### 13章 電界（電場）〔物〕
**クーロンの法則 F = kQq/r²**／**電界 E = F/q**／電気力線／ガウスの法則／
**電位 V = U/q**／点電荷の電位／等電位面／**電界と電位の関係 E = V/d**／
導体と不導体／静電誘導／誘電分極／静電遮蔽

### 14章 コンデンサー 〔物〕　★模試 20/20（ただし「習いたて」）
**電気容量 Q = CV**／平行板コンデンサー C = εS/d／
**直列・並列接続**（抵抗と逆になる）／**静電エネルギー U = ½QV = ½CV²**／
誘電体の挿入／極板間引力／スイッチ切り替え問題

### 15章 電流 〔物〕
オームの法則のミクロな見方／抵抗率と温度／ジュール熱／
**起電力と内部抵抗**／**キルヒホッフの法則**／非直線抵抗（グラフ解法）／
電流計・電圧計／ホイートストンブリッジ／半導体・ダイオード

### 16章 電流と磁界 〔物〕
磁界／**直線電流・円形電流・ソレノイドがつくる磁界**／
**磁束密度 B と F = IBl**／平行電流間の力／
**ローレンツ力 f = qvB**／磁界中の荷電粒子の円運動／
ホール効果／磁性体

### 17章 電磁誘導 〔物〕
**ファラデーの電磁誘導の法則 V = −N ΔΦ/Δt**／**レンツの法則**／
導体棒に生じる起電力（ローレンツ力からの導出）／渦電流／
**自己誘導とインダクタンス**／相互誘導／コイルに蓄えられるエネルギー ½LI²

### 18章 交流と電磁波 〔物〕
交流の発生／**実効値**／抵抗・コイル・コンデンサーそれぞれの交流特性と位相／
リアクタンス／**RLC直列回路とインピーダンス**／**共振**／
電気振動（LC回路）／変圧器／電磁波の発生と性質

## 第5編 原子

### 19章 電子と光 〔物〕
陰極線と電子の比電荷／**ミリカンの油滴実験と電気素量**／
**光電効果**（限界振動数・仕事関数・阻止電圧）／**光子 E = hν, p = h/λ**／
X線の発生と連続X線の最短波長／**ブラッグ反射**／**コンプトン効果**／
**物質波（ド・ブロイ波）λ = h/mv**／電子線回折

### 20章 原子と原子核 〔物〕
原子模型の変遷／**ボーアの原子模型**（量子条件・振動数条件）／
水素原子のスペクトル（バルマー系列など）／
原子核の構成／同位体／**放射線（α・β・γ）と崩壊**／**半減期**／
核反応式／**質量欠損と結合エネルギー E = mc²**／核分裂・核融合／素粒子

# ■ 学習順序と依存関係

```
【土台】1章 運動の表し方 → 2章 力と運動 → 3章 仕事とエネルギー
                                  ↓
        ┌──────────────┬──────────┴──────┬──────────────┐
        ↓              ↓                 ↓              ↓
   3章 運動量      4章 円運動        5章 波の性質    7章 電気抵抗
        ↓              ↓                 ↓              ↓
   2章 剛体      5章 単振動 ←──┐     6章 音        13章 電界
                    ↓          │        ↓              ↓
                6章 万有引力    │    9〜10章 波・音   14章 コンデンサー
                    │          │        ↓              ↓
                    │          │    11章 光        15章 電流
                    │          │        ↓              ↓
                    │          └────12章 干渉      16章 電流と磁界
                    │                                   ↓
              7章 気体分子運動 ←（運動量・力積が前提）  17章 電磁誘導
                    ↓                                   ↓
              8章 気体の状態変化                    18章 交流 ←（単振動が前提）
                                                        ↓
                                                   19〜20章 原子
```

**重要な依存関係（見落としやすいもの）**
- **気体分子運動論 ← 運動量・力積**（分子1個の壁への力積から圧力を出す）
- **交流・電気振動 ← 単振動**（数学的に同じ形。単振動が曖昧だと交流も落ちる）
- **単振動 ← 円運動＋弾性エネルギー**
- **光の干渉 ← 定常波・位相の理解**
- **電磁誘導の導体棒 ← ローレンツ力**

# ■ 必要な数学ツール

| ツール | 使う場所 | 優先度 |
|---|---|---|
| 三角比 sin/cos/tan | 力の分解、斜方投射、干渉の光路差、クーロン力の合成 | 必須 |
| ベクトルの合成分解 | 力、速度、電界の重ね合わせ | 必須 |
| 二次方程式・グラフ | 等加速度運動、放物運動 | 必須 |
| 三角関数（弧度法・単位円）| 単振動、波の式、交流 | 物理選択なら必須 |
| 微分積分の意味 | v-t の傾きと面積、ΔΦ/Δt、p-V の面積 | 理解を深めるのに有効 |
| 指数・対数 | 半減期 | 原子で少し |
| 近似（1+x)ⁿ≒1+nx, sinθ≒θ | 単振り子、干渉、万有引力 | 難関大では必須 |
